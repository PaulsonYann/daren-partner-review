## 本地预览

在本目录运行 `python3 -m http.server 8879 --bind 127.0.0.1`，访问 `http://127.0.0.1:8879/`。也可在上级目录通过项目子路径预览；所有界面和图标资源均为本地静态文件。

## GitHub Pages

main分支根目录为发布源（Settings → Pages → Deploy from a branch），`.nojekyll`跳过Jekyll。无需自购服务器；真实共享资料与服务端权限需要另外部署后端，不由本演示站提供。
