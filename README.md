# 达人伙伴 · 在线评审版

统一体验账号：`review`，口令：`review`。这是公开入口，不提供真实认证或访问保护。

- 全部预置KOL、邮箱、合同和稿费资料均为虚构样例。请勿录入真实资料或真实密码。
- 模拟操作只保存在当前浏览器，不上传、不跨电脑同步；可通过顶部“重置评审资料”恢复。
- 供桌面界面评审，不用于正式业务。审批、付款和上级核验不实际办理；Excel需先转CSV。
- 示例外链为占位，可能无法打开，不代表已接入第三方系统。
- 不包含原系统数据库、账号、日志、备份、内部PRD或服务器代码。

## 本地预览

在本目录运行 `python3 -m http.server 8879 --bind 127.0.0.1`，浏览器访问 `http://127.0.0.1:8879/`。
